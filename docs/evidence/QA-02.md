## 场景结果

| 场景 | 预期行为 | Run / Attempt | 错误码 | 远端状态 | 回收 |
| --- | --- | --- | --- | --- | --- |
| `normal-execution` | 正常执行、独立校验并完整交付 | `SUCCEEDED / SUCCEEDED` | - | 已确认 | destroy 1，active 0 |
| `script-error` | 脚本非零退出，保留部分结果 | `COMPLETED_PARTIAL / FAILED` | `SCRIPT_FAILED` | 已确认 | destroy 1，active 0 |
| `command-timeout` | 超时后确认远端取消 | `COMPLETED_PARTIAL / TIMED_OUT` | `EXECUTION_TIMEOUT` | 已确认 | destroy 1，active 0 |
| `client-cancel` | 客户端取消后进入取消终态 | `CANCELLED / CANCELLED` | `CONFLICT`（取消控制流） | 已确认 | destroy 1，active 0 |
| `cancel-unconfirmed` | 首次无法确认时重试并最终确认 | `CANCELLED / CANCELLED` | `CANCEL_UNCONFIRMED`（首次边界） | 已确认 | destroy 1，active 0 |
| `artifact-limit` | 文件数量超限拒绝发布 | `CANCELLED / CANCELLED` | `ARTIFACT_INVALID` | 已确认 | destroy 1，active 0 |
| `artifact-bytes` | 总字节数超限拒绝发布 | `CANCELLED / CANCELLED` | `ARTIFACT_INVALID` | 已确认 | destroy 1，active 0 |
| `artifact-path` | 路径穿越被拒绝 | `CANCELLED / CANCELLED` | `ARTIFACT_INVALID` | 已确认 | destroy 1，active 0 |
| `artifact-hash` | 已发布文件被篡改后 hash 校验失败 | `CANCELLED / SUCCEEDED` | `ARTIFACT_INVALID` | 已确认 | destroy 1，active 0 |
| `budget-unknown` | usage 未知时暂停且不启动新沙箱 | `PAUSED_ACCOUNTING / -` | `USAGE_UNKNOWN` | 未创建执行 | destroy 0，active 0 |

除 `budget-unknown` 外，每个执行场景均验证了沙箱销毁调用、无活动沙箱和释放标记。
`budget-unknown` 额外验证 `FakeSandbox` 没有收到 `create` 或 `execute` 调用。这保证账目
不确定时不会先产生新的外部执行。`artifact-hash` 的 `SUCCEEDED` attempt 表示产物曾经
成功发布，随后独立 hash 校验发现篡改。这不是把篡改结果重新标记为成功。
