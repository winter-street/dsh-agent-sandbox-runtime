## Boundaries

The SDK timeout abort signal is advisory for the remote process. A timed out or disconnected non-idempotent tool must not be assumed cancelled or replayed; disconnection before a final result is classified as unknown. `location: mcp-host` explicitly records that MCP tools execute on the host side; the integration does not imply sandbox isolation. No third-party MCP deployment, remote authorization system, or hostile server assessment was performed. This evidence demonstrates an actual local MCP service invocation, not an external production service.
