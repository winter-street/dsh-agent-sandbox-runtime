`RuntimeService` 提供 create/get/cancel/resume，`RuntimeStore` 持久化 command intent、payload hash 和结果。相同 commandId 与内容回放原结果，不同内容拒绝。resume 检查 expectedRevision、可恢复暂停状态、原 deadline、未解决 attempt、原 session/scope、预算可用性及未知 usage、代码/配置/产物兼容性；最终以事务和 revision 条件提交状态。恢复不创建新预算域，不重置累计时间或 attempt。人工确认另有单独入口，通用 resume 不绕过审批状态。
