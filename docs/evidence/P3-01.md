## 历史实现与验证记录

Date: 2026-11-17. Status: **local API behavior tested with real loopback HTTP connections; controlled browser exercise passed in P3-03; production deployment binding remains open**.

Files: `src/api/server.ts`, `tests/api/server.test.ts`, `src/core/service.ts`.

### Verified behavior

- Bearer token is required for control endpoints; tokens shorter than 24 characters are rejected at server construction. Query strings are rejected, so credentials cannot be passed in the URL. The token is compared with a constant-time byte comparison when lengths match.
- Requests with a foreign `Origin` are rejected. The API is documented to bind to loopback; an allowed UI origin must itself be local.
- JSON bodies are size-limited and parsed against strict schemas. Run creation, snapshot/list, cancel, resume, approval, and committed artifact routes are exposed.
- Cancel is idempotent for the same command ID and payload; reusing that ID with a different payload conflicts. Resume carries an expected revision, which the service checks against durable state.
- Artifact reads are resolved through the selected run's committed artifact records. An unknown/uncommitted artifact returns 404.
- Responses use `Cache-Control: no-store`; unexpected errors return a generic message instead of internal details.
