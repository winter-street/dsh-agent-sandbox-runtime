The suite composes real Cordis/DSH hooks, original patched budget ledger, Harness/runtime composition, RuntimeService, ArtifactStore and SQLite. The provider emits deterministic responses with **synthetic** token usage. The sandbox is explicitly `FakeSandbox`, so these scenario tests do not run Python or containers. The wrapper rejects a missing patched budget build instead of silently reporting skipped scenarios as success.

| Scenario | Result and boundary |
| --- | --- |
| Ordinary completion | One controlled model settlement, independent host fixture validation, artifact-backed success, tool-call replay without redispatch |
| Enforce/observe soft threshold | Actual recorded request cap 750/1000 from baseline 1000; proposed reduction persisted; original model call automatically settles |
| Policy/ledger reconstruction | Close/recreate Cordis/plugin and SQLite in one process; original snapshot/state retained; threshold notification not repeated |
| Finalize=0 / full request too large | Coordinator automatically generates an explicit partial template with no provider request and no new debit |
| Affordable report | Original automatic hook settles 15 synthetic tokens into finalize once; coordinator verifies receipt chain before accepting optional prose |
| Interrupted report | Original plugin leaves unknown reservation; coordinator returns partial without refund/retry/full success |
| Unknown pause and reconciliation | Consumer interruption before usage blocks new sandbox work, persists `PAUSED_ACCOUNTING`, rejects premature resume; reconstruction retains scope/cursor/artifact; explicit trusted synthetic reconciliation enables resume and reuses original artifact |

The unknown reconciliation is deliberately a trusted fixture input, not provider invoice validation. Starting threshold usage (7000/9500 tokens) is seeded through the actual ledger API, not incurred at an external provider. The runtime does not create or debit another accounting balance.
