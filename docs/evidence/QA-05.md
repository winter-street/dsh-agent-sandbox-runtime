## 交付

- 核验输入、提示、参考实现哈希，拒绝任务身份/分割不一致；在执行与验证边界重核版本，运行期间参考文件改变阻止提交。
- SQLite 调用意图、排他 owner、已提交结果恢复与 JSONL 导出。未知结果保留 pending；普通恢复不自动重发。显式核对仅调用可信 host 的 lookup hook，保持旧 runId，重新验证结果后提交，不调度新槽位。
- 驱动请求不包含参考答案；执行和独立验收为两个可信 host hooks。读回持久化结果仍核对原槽位、run、manifest、预算和配置。
- 比较时固定版本/策略配置/预算，去重调用，拒绝跨 run 重复计量；未知用量保持未知，已知超额保留下界，辅助调用纳入总消耗。校准或未知必需检查不能标最终效果数据完整。
- 构建修复：`pnpm build` 与 `pnpm check` 均复制客户端静态资源到 `dist/client`。此前仅 TypeScript 编译不能使构建后的 API 正常读取界面资源。
