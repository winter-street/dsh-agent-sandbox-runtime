These are real Cordis/DSH request/stream registry hooks and real original budget hooks, not an expected-parameter calculation. Scenario model output/usage is deterministic; starting usage is seeded through trusted original-ledger reservation/settlement. The downstream adapter records the exact request it receives. Runtime SQLite stores mode, stage, actual/proposed limits and reason codes in `policy.decision`; the cap reduction reason is `OUTPUT_CAP_REDUCED` and threshold reason is `BUDGET_PRESSURE`.

The request hook preserves a trusted baseline rather than repeatedly shrinking the previous reduced cap. The final `llm/stream` hook re-estimates complete assembled input and rejects cap changes/oversized/unbounded requests before downstream budget/provider execution. Code/structured output keep their required minimum. The actual iterator gate tracks active calls; reduced future concurrency returns bounded retryable waits, without cancelling the existing call. Explicit spawn admission rejects new agents at the configured pressure stage. Observe mode still enforces hard unknown/cancel/deadline/capacity/concurrency boundaries. The workflow must call the explicit spawn gate; arbitrary host-created agents are not globally intercepted by this helper.

`RuntimeService` applies persisted policy before sandbox tool dispatch. Unknown usage causes `PAUSED_ACCOUNTING` before a new execution; the scenario verifies no additional sandbox attempt starts. Model lifecycle accounting remains owned by the original plugin and is not duplicated in the policy layer. Automatic model switching remains disabled/unimplemented.

The controlled tests do not establish real provider usage, in-flight HTTP interruption semantics or monetary savings. A separate [real OpenSandbox probe](P1-06-harness.md) verifies the basic host/budget/runtime/sandbox chain with a controlled provider; the soft-threshold matrix itself uses a fake sandbox. Validation commands/totals are in [P2-12](P2-12.md). The complete application/profile and fixed real-model task gates remain open.
