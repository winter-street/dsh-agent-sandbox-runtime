实现：`src/core/checkpoint.ts`、`src/contracts/runtime.ts`、`src/storage/index.ts`、`src/core/service.ts`。checkpoint 使用严格的 schemaVersion 2，保存原 run、输入哈希、策略版本、预算域引用、步骤输入哈希、attempt 代码哈希、已提交产物引用和事件游标，不保存或覆盖预算余额。旧版、未来版及无法解析的内容明确拒绝，需要显式迁移，不自动补填未知历史。
