# v0.2 · 预算、恢复与软限制版本

日期为 2026-11-19（Asia/Shanghai）。原始 G2 已按 P2-01—P2-12 和 QA-03 验收，逐项映射见 [QA-03](../evidence/QA-03.md)。该版本完成原计划的首版简历证据目标，实现及修复位于当前共享工作树，版本基线见 [P0-01](../evidence/P0-01.md)。

## 已交付行为

- 复用原预算插件的原子预留、结算去重、unknown 保留及可信迟到用量核对，根与子会话共享原预算域。
- checkpoint 记录原 scope、deadline、运行时指纹、事件游标、策略状态及产物。已确认结果按原 attempt/execution 恢复，未知结果进入保守核对流程。
- 软限制按使用压力收紧请求 cap 并持久化通知和阶段。收尾保留独立额度，无法支付时输出明确的部分交付。
- 可信管理端调整原预算后，显式恢复预算暂停任务可以解除收尾锁定。命令结果、RUNNING 状态、操作原因及 checkpoint 原子提交，重放及重开保持幂等。

## 真实环境证据

原预算插件与实际 OpenSandbox 的独立 worker SIGKILL 探针覆盖 dispatch intent、沙箱执行后和产物发布后三个窗口。报告分别为 3/3、3/3 和 6/6，原预算域及期限保留，迟到可信用量结算一次。该探针模型调用为零，用量核对由受控输入提供，命令及报告见 [N02](../evidence/N02-budget-process-recovery.md)。

真实 DeepSeek 与 OpenSandbox 演示已独立验证 statistics.json、report.md 和 chart.svg，共使用 3974 tokens，其中 work 3908、finalize 66，未知调用及未结预留均为零。取件步骤见 [演示说明](../demo.md)，报告映射见 [P1-08](../evidence/P1-08.md)。真实长任务与强杀恢复见 [P3-06](../evidence/P3-06.md)。

## 覆盖边界

本轮按既定设计，将可信宿主对 PAUSED_BUDGET 的显式恢复视为操作员解除收尾锁定的意图。新增调额续跑分支已经过受控集成回归，该分支的外部模型与 Docker 组合仍待实测。
